# Prototype Limitations

This prototype intentionally does not attempt to be production-complete.

## Not included

- authentication
- billing
- multi-tenancy
- mass submissions
- production-scale scraping
- dozens of live integrations
- full outreach CRM
- full SEO analytics
- automated link purchasing
- unrestricted browser automation
- complex multi-agent orchestration

## Synthetic company

Nordhaus is fictional demo data.

## External platforms

Platform records are research data. API capabilities must be verified before implementation.

A platform being listed in the dataset does not imply that automated publication is supported.

## Mock execution

The primary end-to-end demonstration uses MockProvider so the workflow can be demonstrated without real credentials or external side effects.
